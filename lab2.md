# Лабораторная работа — вариант 3: движение пешеходов (Boids)

## Запуск

1. Установить Python 3.10+.
2. Открыть терминал в папке проекта.
3. Установить библиотеку: `pip install pygame`
4. Запустить: `python main.py` (на Windows можно `py main.py`).

## Управление

- `Пробел` — пауза/продолжить.
- `R` — повторить моделирование с текущими параметрами.
- `S` — сохранить таблицу `results.csv` с временем выхода каждого пешехода.
- `1`/`2` — уменьшить/увеличить количество пешеходов (не ниже 20).
- `3`/`4` — сузить/расширить дверной проём.
- `5`/`6` — уменьшить/увеличить вес правила разделения.
- `Esc` — закрыть окно.

При изменении параметра моделирование начинается заново. Чтобы сравнение было воспроизводимым, расположение пешеходов задано одним и тем же зерном генератора (`seed=7`) на первом запуске. При каждом `R` начальная расстановка повторяется для сопоставимости экспериментов.

## Модель

- Двумерный прямоугольный коридор со стенкой и одним проходом.
- 30 пешеходов по умолчанию (минимум 20).
- Цель — правая граница, отмеченная зелёной полосой.
- Правила: центрирование (cohesion), выравнивание (alignment), разделение (separation) и движение к цели (goal seeking).
- Скорость и ускорение ограничены.
- Максимум 900 шагов симуляции: условие лабораторной «не менее 500» выполнено. Если все вышли раньше, счётчик продолжит идти до 500 шагов (минимум по заданию).
- Время достижения выхода фиксируется индивидуально.

## Рекомендуемые эксперименты

1. 20 / 30 / 50 пешеходов при исходных остальных параметрах.
2. Проём 50 / 95 / 170 пикселей, количество 30.
3. Вес разделения 0.6 / 2.2 / 3.8, остальные значения исходные.

Для каждого случая запишите фактическое количество вышедших, среднее время выхода и количество шагов. Используйте `S` для сохранения CSV; перед следующим экспериментом переименуйте файл, иначе он перезапишется. Сделайте скриншоты на разных этапах.

## Ограничения модели

Это упрощённая двумерная модель, а не точная физика людского потока. Мягкая коррекция столкновений не гарантирует идеального отсутствия перекрытий агентов при очень плотной толпе. Логика поведения носит демонстрационный характер.
