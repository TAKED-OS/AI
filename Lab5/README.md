# Лабораторная работа №5

[Отчёт](Report.md) · [Программа](main.py) · [Экспериментальные данные](results)

Python 3.10 или новее. Внешние зависимости отсутствуют. Из корня репозитория:

```sh
python Lab5/main.py --experiments --output Lab5/results
python Lab5/main.py --population 5 --pc 0.8 --pm 0.05 --generations 30 --seed 23 --output Lab5/results/custom
```

В режиме `--experiments` программа использует четыре набора параметров из отчёта. В одиночном запуске можно менять размер популяции, вероятности и число циклов эволюции. Случайная начальная популяция имеет номер 0. В каждом каталоге результата сохраняются полный журнал, CSV по особям, CSV по поколениям и график SVG.
